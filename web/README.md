# مصنع السلطان - نسخة الويب

نسخة ويب من تطبيق مصنع السلطان لنظام متابعة أداء المصنع.

## المميزات

- ✅ تسجيل دخول آمن
- ✅ لوحة معلومات شاملة
- ✅ إدارة المستخدمين والصلاحيات
- ✅ تتبع مراحل الإنتاج
- ✅ إدارة الصيانة والمالية
- ✅ الأهداف والمؤشرات
- ✅ نفس البيانات المشتركة مع نسخة الموبايل

## البدء السريع

### المتطلبات

- Node.js 18+
- pnpm (أو npm/yarn)

### التثبيت

```bash
cd web
pnpm install
```

### التطوير

```bash
pnpm dev
```

سيفتح التطبيق على `http://localhost:5173`

### البناء للإنتاج

```bash
pnpm build
```

## الهيكل

```
web/
├── src/
│   ├── pages/           # صفحات التطبيق
│   ├── components/      # مكونات React
│   ├── hooks/           # React hooks مخصصة
│   ├── services/        # خدمات API
│   ├── styles/          # ملفات CSS
│   ├── App.tsx          # المكون الرئيسي
│   └── main.tsx         # نقطة الدخول
├── index.html           # HTML الرئيسي
├── package.json         # المتطلبات
├── vite.config.ts       # إعدادات Vite
└── tailwind.config.js   # إعدادات Tailwind
```

## التكامل مع API

التطبيق يتصل بنفس API الخادم المستخدم في نسخة الموبايل:

- `http://localhost:3000/api` - API endpoints
- `http://localhost:3000/trpc` - tRPC procedures

## البيانات المشتركة

جميع البيانات مشتركة بين نسخة الويب والموبايل:
- بيانات المستخدمين
- الأهداف والمؤشرات
- سجلات الإنتاج
- المرفقات والملفات
- الصلاحيات والأدوات
